# 최상단 아이콘 툴바 검증 — 2026-10-26

## 구현

- 승인된 선형 아이콘을 `AppToolbar.cs`의 벡터 좌표로 구현해 테마색/DPI에 맞춰 생성한다.
- 툴바는 홈과 문서의 최상단, 문서 탭 위에 고정한다. 순서: 새 문서·열기·저장·인쇄 / 실행 취소·다시 실행 / VIEW·편집 모드·문서 폭 / 검색·키워드 강조. 현재 문서 닫기는 오른쪽 끝에 둔다.
- 문서 폭 아이콘은 기본46rem→넓게70rem→창 맞춤을 순환한다. 화살표 메뉴에서 세 항목을 직접 선택할 수 있으며 현재 상태의 아이콘과 체크 표시를 제공한다.
- 모드 아이콘은 VIEW/편집 상태에 따라 변경한다. 검색·키워드 강조 패널과 활성 탭·편집 이력·읽기 전용 여부에 따라 버튼 상태를 갱신한다.
- 이전 문서 내부의 두 폭 버튼은 제거했다. 우클릭 메뉴와 기존 단축키를 유지하고 다시 실행 Ctrl+Y/Ctrl+Shift+Z를 지원한다.
- 각 아이콘에 한국어 툴팁/단축키/접근성 이름을 제공한다. 툴바 파일 드롭도 기존 파일 열기 경로에 연결했다.
