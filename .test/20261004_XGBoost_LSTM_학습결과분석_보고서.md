## 2. 용어·지표 읽는 법

| 용어·지표 | 뜻 |
|---|---|
| XGBoost | 작은 결정 트리를 순차 결합해 고장 점수를 내는 모델. 이번에는 통계·물리 특징을 입력으로 쓴다. |
| LSTM | 시간 순서의 변화를 기억하며 판단하는 신경망. 이번에는 창 안의 신호 시퀀스를 입력으로 쓴다. |
| 시퀀스 | 시간 순서대로 정렬된 신호 값 묶음. LSTM은 이 순서의 변화를 학습한다. |
| seed | 학습의 무작위 선택을 재현하는 번호. 다른 seed의 결과 변동으로 안정성을 확인한다. |
| Precision | 고장이라고 알린 분석창 중 해당 고장 라벨이 있는 비율. 낮으면 오탐이 많다. |
| Recall | 실제 고장 라벨이 있는 창 중 검출한 비율. 낮으면 고장을 놓친다. |
| F1 | Precision과 Recall의 조화평균. 한쪽만 낮아도 내려간다. |
| Macro F1 | 고장별 F1의 동일 가중 평균. 이번 저장값은 유효 Test 고장 UV·OC 2종 평균이며, 이전 6종 평균과 범위가 다르다. |
| TP | 고장 라벨이 있고 모델이 해당 고장을 검출한 창. |
| FP | 고장 라벨은 없는데 해당 고장으로 예측한 창. 다른 고장의 창도 포함될 수 있다. |
| FN | 고장 라벨이 있는데 해당 고장을 예측하지 못한 창. |
| TN | 고장 라벨이 없고 해당 고장으로 예측하지 않은 창. |
| Val | 모델과 임계값을 선택하는 검증 데이터. Test와 분리한다. |
| Test | 설정 선택 후 평가하는 데이터. 반복 튜닝에 사용하면 새 독립 평가가 필요하다. |
| Train | 모델과 입력 전처리의 기준을 학습하는 데이터. |
| AP | Average Precision. 연속 점수의 순위에 따른 정밀도·재현율을 요약한다. |
| threshold | 모델 점수가 이 값 이상이면 해당 고장으로 알리는 경계. 실제 운영 경계를 사용한다. |
| epoch | 학습 데이터를 한 차례 순회하는 단위. 마지막 epoch와 선택 epoch가 다를 수 있다. |
| patience | 충분한 Val 개선 없이 기다릴 트리/epoch 횟수. 지나면 조기중단한다. |
| min_delta | Val 지표가 이 값보다 더 개선돼야 선택 모델을 갱신한다. |
| 조기중단 | Val 지표가 정해진 유예 횟수 동안 충분히 좋아지지 않으면 학습을 멈추는 방식. |
| Normal FA/h | Normal의 오탐 이벤트 수 / Normal 노출 시간(h). 오탐 창 수와 분모가 다르다. |
| SHA256 | 파일 바이트의 동일성을 확인하는 해시. 라벨의 정답 여부를 보증하지 않는다. |
| 분석창 | 로그에서 자른 시간 구간. 겹치는 창 수를 독립 고장 사건 수로 세면 안 된다. |
| 캠페인 | 같은 시험 일시·장비·조건을 공유하는 계열. 다른 파일이어도 독립 새 시험은 아닐 수 있다. |
| latch | 고장 원인이 사라진 뒤에도 고장 비트가 유지되는 동작. 이번 불일치의 가설이며 원본 확인이 필요하다. |
| 모델 점수 | 모델의 출력값. 운영 threshold와 비교하며 보정된 실제 고장 확률로 단정하지 않는다. |
| UNVALIDATED | 유효 검증 조건을 만족하지 않은 타깃. 모델 파일이 있어도 검증 완료나 운영 승인으로 취급하지 않는다. |
| VALIDATED | 소스가 정한 검증 조건을 만족한 평가 타깃. 독립 현장 시험의 증명과는 구분한다. |
